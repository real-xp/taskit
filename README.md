# TaskIt

A simple yet elegant app that allows one to do task management.

## Features
- Task Lists with CRUD operations
- Tasks inside Task Lists with CRUD operations

## Technologies Used
- Python

## Build And Run
- Clone the repository.
- Install the required packages.
- Run `main.py` using command-line.

## Test
Follow the instructions on screen to test functionality of the code.
